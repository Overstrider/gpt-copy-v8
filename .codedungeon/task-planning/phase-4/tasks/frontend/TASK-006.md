## Objective
Create zod schemas, typed API fetch helpers, TanStack Query hooks, and native SSE stream parsing hook.

## Context
- Frontend consumes only the backend API; no OpenRouter access belongs here.
- Use zod validation for API responses and structured backend errors.
- useStreamMessage should parse token, done, and error SSE frames from the backend stream endpoint.

## Write Scope
- frontend/src/lib/schemas.ts
- frontend/src/lib/types.ts
- frontend/src/lib/api.ts
- frontend/src/hooks/useConversations.ts
- frontend/src/hooks/useMessages.ts
- frontend/src/hooks/useCreateConversation.ts
- frontend/src/hooks/useStreamMessage.ts

## Acceptance Criteria
- Schemas cover Conversation, Message, SendMessageResponse, ErrorBody, and Health shapes.
- apiFetch defaults NEXT_PUBLIC_API_BASE_URL to http://localhost:8080 and throws ApiError for structured backend errors or zod parse failures.
- Query hooks use stable query keys for conversations and messages.
- Streaming hook aborts in-flight requests and invalidates conversations/messages on done.

## Verification Commands
- npm --prefix frontend run lint
- npm --prefix frontend run test -- --runInBand

## Risk Notes
- The Playwright route mocks must match the URL generated by apiFetch.
- Avoid unsafe TypeScript casts in lib/api.ts and hooks.
